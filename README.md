# SQL Interview Mastery

8주 80문제를 목표로 하는 PostgreSQL 중심 SQL 면접 훈련 저장소입니다.

## 목표
- SQL 코딩테스트: 정확성, 예외 처리, 성능, 가독성 및 설명력 훈련
- 핵심 영역: JOIN, GROUP BY, CTE, Window Function, 비즈니스 분석 SQL, EXPLAIN
- 모드: Practice / Interview / Review / Explain / Mock Test

## 저장소 구성
- `database/`: 스키마 및 재현용 데이터
- `problems/`: 문제 설명, 요구사항, 예상 출력
- `solutions/`: 사용자가 직접 작성한 SQL
- `tests/`: 테스트 케이스 및 검증
- `notes/`: 오답 및 개념 정리
- `mock_interviews/`: 모의면접 기록
- `progress/`: 점수 및 학습 진도

## 시작하기
1. `project_instructions.md`를 ChatGPT 프로젝트 지침에 적용합니다.
2. 로컬 PostgreSQL을 설치하거나 `docker compose up -d`로 실행합니다.
3. `database/`의 스키마와 샘플 데이터를 준비하고 문제를 풉니다.
4. SQL 풀이를 `solutions/`에 기록하고 실행 결과와 피드백을 `progress/`에 남깁니다.

> 정답 SQL을 미리 공개하지 않습니다. `problems/`와 `solutions/`는 문제 및 사용자의 시도를 기록하는 곳이며 초기에는 예제 정답을 넣지 않습니다.
